# Topf &amp; Tempo

Der Mitkoch-Podcast. Ein Gericht pro Folge, rund zehn Minuten, zum Mitkochen.
Für Familien und Berufstätige: normale Zutaten, normale Küche, ein Topf wo es geht.

## Inhalt dieses Repos

| Ordner | Inhalt |
|---|---|
| `index.html` | Die Webseite (eine Datei, Hell/Dunkel, mobil) |
| `skripte/` | Die Sprechskripte der Folgen, inklusive Timecodes und Shownotes |

## Die Folgen

1. **One-Pot-Pasta** — ein Topf, zwanzig Minuten, kein Abwasch
2. **Kichererbsen-Curry** — das Gericht für den leeren Kühlschrank
3. **Das Blech** — Hähnchen und Gemüse aus dem Ofen

## Moderation

Zwei Stimmen, klare Rollen: Mira kocht routiniert und gibt das Tempo vor,
Jonas kocht mit und fragt nach. Vertonung über ElevenLabs
(Mira: „Nadine – Friendly Conversational", Jonas: „Mats – Warm and Genuine").

## Veröffentlichung

Die Webseite läuft über GitHub Pages. Audiodateien liegen nicht im Repo,
sondern beim Podcast-Hoster.
